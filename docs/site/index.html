Loophole

An RL environment (Harbor + MCP) where an LLM agent solves 3D disentanglement puzzles in a MuJoCo simulation. The agent only talks to the simulator over MCP, from a separate container, so it never sees the simulator, the solver or the reference.

Two tasks

Both are Harbor tasks with the same structure: a simulator sidecar serves the MCP tools, and a separate verifier container replays the episode log to score it.

Alpha 1.0 tasks/loophole-alpha

Two identical alpha-shaped tubes are interlocked. Tube A is fixed; the agent grabs tube B and moves it with bounded steps until it can slide away along a straight line without touching tube A.

  • Geometry and reference path from Zhang et al. 2020, fetched at build time, never committed.
  • The way out is a narrow tunnel in SE(3) with millimetre clearance.

Rat Trap tasks/loophole-rattrap

A closed string loop with a mouse bead starts wrapped around a dowel of a wooden frame. The agent frees the loop with two grippers, on an inextensible capsule-chain cord.

  • The reference is a human teleoperated solve, recorded in the simulator and replayed.
  • No solver, planner or search anywhere in its pipeline.

How it is scored

One number

The verifier writes a single episode score. Any solve beats any non-solve, faster solves score more, and forcing the pieces together scores zero.

Geometric goal

Solved means free escape by translation: the moving piece can slide to infinity along some direction without contact. No tunable distance threshold.

Replayed, not trusted

A no-network verifier container replays every logged action in a fresh simulator, checking hashes of the puzzle, config and every state. Nothing the agent writes is read.

Red-teamed

Malformed arguments, budget burning, oscillation, teleporting by re-grabbing and container escape attempts are each tested. See Reward red-team.
